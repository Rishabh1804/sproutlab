Rules the arc earned

✓ Record only what was shown

gvConfirmRecord(row, shownKind); never a broader kind, never a fallback while the check asks.

✓ A tap settles which, a retype settles the number

Choosing between named records is not evidence a number is right.

✓ An optional source, never a second engine

"As of a date" passes rows to the one check; the no-argument path stays byte-identical.

✓ Bind the panel

Re-check at the tap; redraw, never write past a change.

✓ Defence at the write

What the surface forbids, the record function refuses too.

✓ Fail closed to the safer surface

Anything unsettled saves unconfirmed; the dose chip still asks at dose time.

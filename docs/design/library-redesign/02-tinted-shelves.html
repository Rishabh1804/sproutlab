§Tint · the alarm hierarchy made visual. Four ambient zones — sage / amber / rose / sky — let a half-awake parent scan to the right band by colour. The warn band uses the same --rose-light token as the Emergency entry but at band intensity (no siren-fill icon, no 40px rose disc, label not Fraunces-loud): the documented gap between an ambient wash and a loud signaling fill is exactly what keeps the soft "wait" zone from competing with the one true alarm pinned above it.

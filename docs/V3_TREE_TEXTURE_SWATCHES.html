v3.0 Tree — background texture swatches

Six approaches, same boss node + secondary node + connector overlaid on each. Compare how the foreground reads.

What to look for: can you read the node text? Does the texture support or fight the content? Does it feel "cozy nursery journal" or wrong-register? Each swatch has my verdict; pick one (or "do this but lighter" / "blend 3+4" etc.) and I'll lock the rebuild.
A

A. Clean cream (baseline)

What we have now. Subtle radial gradient overlay; no texture.

Verdict: too light. Reads as web app, not artifact.

B

B. Light parchment

Fine grain (1px horizontal + 1px vertical at very low opacity) + soft sepia spots. Subtle warmth.

Verdict: good middle ground. Quietly textured, still calm.

C

C. Aged paper

Stronger grain (diagonal crosshatch at low opacity) + corner stains + warmer base. Maximum texture before legibility cost.

Verdict: dramatic, but starts fighting node text. May overwhelm at 32 nodes.

D

D. Marble vein (Imperator-style)

Diagonal veining + high-contrast highlights. Closest to the Imperator visual register you cited.

Verdict: powerful for grand-strategy registers — wrong for nursery journal. Breaks the warm-sturdy-calm brief.

E

E. Linen weave

Cross-hatch at 1.5px in both axes + soft vignette. Reads as fabric/journal-cloth. Nursery-aligned.

Verdict: distinctively SproutLab. Tactile but quiet.

F

F. Watercolor wash

Soft pastel washes of sky/lavender/amber/peach blooms over warm cream. Almost no grain — colour-only atmosphere.

Verdict: most "warm + sturdy + calm" of the six. Domain-token palette is already woven in.

G

G. F + E (watercolor + linen)

Watercolor blooms underneath, linen cross-hatch (1.5px both axes, ~3% opacity) on top. Atmosphere from F, tactility from E.

Verdict: my recommendation — fabric/journal-cloth feel with the warm pastel atmosphere. Calm + tactile + on-brand.

H

H. F + B (watercolor + parchment)

Watercolor blooms underneath, parchment fine-grain (1px H+V separately) + soft sepia spots. Atmosphere from F, document/page-aged feel from B.

Verdict: reads as "aged journal page with a warm wash" — leans more "chronicle/canon" than G's "nursery cloth." Both work; pick based on the artifact's voice.

How to read these:
  • The large indigo circle is a boss node (v3-3); the smaller rose circle is a Wave-1 node (v3-1); the connector is a standard edge.
  • All eight have the exact same node treatment overlaid — only the background varies.
  • The "A" through "H" tag in the corner is what a tier-label would look like rendered against each background.
The two finalist hybrids:
  • G (F+E) — watercolor atmosphere + linen cross-hatch. Reads as nursery cloth / fabric journal. Strongest "warm + sturdy + calm" feel; the cross-hatch is symmetric so it doesn't pull the eye in a direction.
  • H (F+B) — watercolor atmosphere + parchment grain + soft sepia spots. Reads as aged journal page with a warm wash. Leans more "chronicle/canon document" — feels like a planning artifact.
The pick depends on what voice you want the artifact to speak in:

G says: this is your daughter's tracking journal — soft, daily, intimate.
H says: this is a planning chronicle for a long-running build — sturdy, deliberate, official.

For the v3.0 progression tree specifically, I lean H — it's a planning document, not a daily-use surface. For the actual app surfaces (home tab, info tab, today-so-far), G would be the right choice. Different artifacts get different textures.

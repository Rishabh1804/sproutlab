The posture

The app used to open onto a 16-section cockpit. It now opens onto a calm front door — warm-wave hero, one honest "today" line, three soft doors (Log / Today / Ask). The cockpit is one tap behind, as "Today". The organizing principle: calm by default, but Care pre-empts the calm — a fever, an overdue vaccine, a due Vit D3 dose steps forward loud-rose and routes the parent straight to the fix.

Three durable patterns (candidate Codex canon)

Pattern 1

Deep-link to the fix, not the inventory

An actionable alert must land on the surface where the action lives — never a read-only summary/management card. The Vit D3 pre-empt routed to the Meds inventory card (no way to log); fixed to land on the Home reminder card's Done now / Done at… / Skip.

✓ id-contract: target supp-alert-${idx} aligns only because both functions derive idx from the same filter, same order.

Pattern 2

Crowd-fit the hero

When Care pre-empts push Emergency below the fold, the hero collapses to a compact "Start with [picker]" row, keeping the safety-critical card reachable without a scroll. Measured against the viewport (not a count), re-measured from full state — relaxes back when there's room, never sticks.

Pattern 3

Relabel, don't rename

Introduce the new id (landing) as default; keep the old (home) bound to its surface, change only the label ("Today"). Preserve the threaded string-contract with a derived set PANEL_IDS = […TAB_ORDER, 'home'] — and migrate every consumer (K-1 caught the one that wasn't).

Meta

Edict V finds seams, not violations

Cipher caught handleSafeExit still treating home as the exit base after the front door became landing. No single Governor owned it — it lived in the seam between "the new default" and "the exit gesture". That is exactly what the cross-jurisdiction pass exists to catch.
